# 脑机状态驱动新中式视觉生成系统 · 原型 0.1

一个可直接运行的网页参数化原型：六维脑机状态驱动两种新中式视觉路线，同一输入可对照，可导出作品与会话，预留 EEG / PM / TouchDesigner / 3D 接口。

不宣称情绪识别或疗愈。状态只驱动视觉语法。

---

## 运行

```bash
# Windows 可双击 start.bat，或：
cd new-chinese-bci
python -m http.server 8000
# 打开 http://localhost:8000
```

实时模式（可选）：

```bash
pip install -r server/requirements.txt
python server/websocket-server.py      # ws://127.0.0.1:8765，10 Hz 模拟推流
# 页面左侧切到「实时」
```

必须用 HTTP 服务打开，不能直接双击 `index.html`（ES modules 需要同源）。

## 界面

- **左**：输入模式（模拟 / 手动 / 实时）、视觉风格（简约典雅 / 材质对比）、四种状态预设（安静 / 展开 / 集中 / 波动）、纹样母题、播放与重置。
- **中**：主视觉，左下角一行状态短句，右上角信号状态。
- **右**：六个状态值（手动模式可直接拖动）、当前映射参数、导出（PNG / JSON / 会话 / 回放）、模拟断流。

`compare.html`：左右两屏同源对照，可同时暂停、切预设、分别导出。

## 状态参数

| 参数 | 范围 | 视觉意义 |
|---|---:|---|
| `quality` | 0–1 | 数据可信度：透明度、更新速度 |
| `activation` | 0–1 | 活跃程度：速度、亮度、发光 |
| `stability` | 0–1 | 稳定程度：对称、秩序、留白 |
| `complexity` | 0–1 | 结构复杂度：数量、层次、颗粒 |
| `change` | 0–1 | 相对变化：扰动、呼吸、开合 |
| `focus` | 0–1 | 集中程度：主体突出、线宽、核心比例 |

无效输入：`quality < 0.35` 时降低更新并保持画面；实时断流显示「等待信号」，不崩溃、不随机漂移。

## 两种风格

**风格 B · 简约典雅**
单一主体、2–4 色、留白 30% 以上、低动态。五母题：圆形花卉、几何曼陀罗、简化凤凰、传统云气、传统花叶。稳定度控制对称份数与留白，复杂度控制点线面数量，激活度控制克制的旋转与生长。

**风格 A · 材质对比 / 酸性新中式**
径向多层（≤6 层）、玻璃边缘、金属丝带、液态珠体、虹彩渐变、发光核心。激活度控制旋转/丝带/发光，复杂度控制层数与珠体粒子，变化控制局部扭曲，集中度保证中心不失焦。

两条路线共享同一份状态与同一套参数名，便于「同一输入、不同审美输出」的比较。

## 验收

功能：浏览器可启动；两风格可切换；四预设可切换；可暂停/继续；可导出 PNG / JSON；模拟连续变化；断流不崩溃。

视觉：A/B 明显不同；B 纹样清楚、信息量少、留白足；A 有材质对比但仍有中心和结构；动态不闪烁跳变；状态变化可被感知。

研究：每帧状态可记录；映射参数独立；视觉代码不依赖设备；模拟可替换为 PM/EEG；同一输入可回放；两风格可比较。
