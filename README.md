# 脑机状态驱动新中式曼陀罗 · 原型 0.5

一个可直接运行的网页参数化原型：六维脑机状态驱动**同一张曼陀罗**，用三种形式语言呈现（绢本平涂 / 套印叠影 / 琉璃折光），同一状态可三版并排对照，可导出作品与会话，预留 EEG / PM / TouchDesigner / 3D 接口。

不宣称情绪识别或疗愈。状态只驱动视觉语法。

---

## 运行

```bash
# Windows 双击 start.bat 即可：自动挑 Python、起脑电服务、起静态服务、开浏览器
# 手动等价于：
cd new-chinese-bci
python serve.py 8000
# 打开 http://localhost:8000
```

单版直达：`index.html?style=silk`（绢本平涂）/ `?style=lac`（套印叠影）/ `?style=glass`（琉璃折光）。

实时模式（可选）：

```bash
pip install -r server/requirements.txt
python server/websocket-server.py      # ws://127.0.0.1:8765，10 Hz 模拟推流
# 页面左侧切到「实时」
```

真实 EEG 数据（DEAP，替代尚未到手的 EPOC X）：

```bash
python data/fetch_deap.py                                  # 一次性下载 2.9 GB + 解压
start-eeg.bat                                              # 或手动：
.venv/Scripts/python.exe server/eeg-deap-server.py --subject 1 --trial 0 --loop
# 同一端口 8765、同一消息格式，网页端不用改
```

必须用 HTTP 服务打开，不能直接双击 `index.html`（ES modules 需要同源）。

## 界面

- **左**：输入模式（模拟 / 手动 / 实时）、形式语言（平涂·绢本 / 叠影·套印 / 折光·琉璃）、四种状态预设（安静 / 展开 / 集中 / 波动）、播放与重置。
- **中**：主视觉，左下角一行状态短句，右上角信号状态。
- **右**：六个状态值（手动模式可直接拖动）、当前映射参数、导出（PNG / JSON / 会话 / 回放）、模拟断流。

`compare.html`：三屏同源对照，可同时暂停、切预设、分别导出。

## 状态参数

| 参数 | 范围 | 视觉意义 |
|---|---:|---|
| `quality` | 0–1 | 数据可信度：透明度、更新速度 |
| `activation` | 0–1 | 活跃程度：速度、亮度、发光 |
| `stability` | 0–1 | 稳定程度：对称、秩序、留白 |
| `complexity` | 0–1 | 结构复杂度：数量、层次、颗粒 |
| `change` | 0–1 | 相对变化：扰动、呼吸、开合 |
| `focus` | 0–1 | 集中程度：主体突出、线宽、核心比例 |

无效输入：`quality < 0.35` 时降低更新并保持画面；实时断流显示「等待信号」，不崩溃、不随机漂移。

## 一张曼陀罗，三种形式语言

图案只有一份。`src/mandala.js` 按状态算出环带半径、瓣数、瓣形、籽粒位置，三种渲法读同一个 `G`，
所以三版之间可以逐瓣对上：哪一片在外、哪一片是主瓣、哪一圈是缠枝节点，三版完全一致。
差别只允许出现在「这是用什么做的」。半径以图案外缘为 1.0：

| 环带 | 半径 | 内容 |
|---|---|---|
| 边饰 | 0.952–1.000 | 盘金双环 + 打籽点 |
| 外瓣 | 0.545–0.943 | 长瓣 + 瓣间短瓣（长瓣的 45%），长短交替出节奏 |
| 缠枝 | 0.454–0.518 | 正弦主枝 + 叶 + 节点花 |
| 内瓣 | 0.240–0.426 | 双裂瓣，与外瓣错开半格 |
| 中心 | 0–0.142 | 打籽饼 + 四瓣十字 |

**一 · 平涂 · 绢本（silk）**
色块 + 同心退晕（瓣缘暗、瓣脊亮）+ 白描墨线 + 盘金 + 丝理 + 极淡经纬。
每一块颜色都有边、每一层都有台阶，这是「绣」与「填色」的分界。

**二 · 叠影 · 套印（lacquer）**
同一张图印三到四遍，每遍整体微旋、微缩、微移，色温由冷到暖递减，金线逐层减淡。
错位处露出前后两层轮廓，读作重影而不是模糊。不靠透明度堆叠——那是上一版满地糊掉的根因。

**三 · 折光 · 琉璃（glass）**
WebGL2 多趟着色器，四趟由外向内合成，每趟按法线偏移从上一趟取样做折射，RGB 分离取样做色散。
瓣形半宽复现 `petalPath` 的实际收窄量（≈ wid·c·0.80），否则同一组参数在这版会胖一倍。
不做方向光高光——那是光源假设，会立刻读成塑料。

## 配色

一个主色系加一个点缀色，靠明度分层，不做四色等量轮转：四色轮转立刻读成彩色拼盘。
三套调色板共用同一色序（绛深 / 绛中 / 墨青 / 赭浅），所有瓣的色位由 `mandala.js` 里的 `cIdx` 定，
所以同一片瓣在三版里落在同一个色位上；`glass` 版通过 `uOutC` 数组把 `cIdx` 原样传进着色器。

## 通透感怎么做的

「通透」不是把底色调亮，是让背景具备可被看进去的深度。`atmos.js` 四件事：

1. **底不取纯黑**：中心抬亮到 `#12202F`、边缘压到 `#020408`，色相始终偏青蓝，大面积看起来是「空间在背后」而不是「一块黑板」。
2. **背后一层微光**：`screen` 叠加的宽半径光晕，抬升中心，主体因此浮起来。
3. **三层景深粒子**：420 颗，远层细密暗淡、中层适度、近层少而柔；按 depth 分配上浮速度形成视差，横向慢摆，明灭幅度极小不闪。
4. **暗角 + 颗粒**：暗角压边不压死，128px 颗粒贴图打散渐变色带。

折光版的对应实现在着色器里：同一套渐变 + 两个尺度的低频噪声雾 + 网格浮尘。

## 真实 EEG：用 DEAP 替代 EPOC X（设备未到手）

选 DEAP 而不是 EEGMMIDB 的原因：DEAP 的 32 导 EEG 通道顺序前 15 个为
`Fp1 AF3 F3 F7 FC5 T7 P7 O1 O2 P8 T8 FC6 F4 F8 AF4`，与 EPOC X 的 14 导几乎一一对应，
因此**特征代码与映射规则可以原样迁移到真机**；且每个 trial 附带 valence / arousal /
dominance / liking 评分，能量化「六参数是否真的跟着情绪维度动」，这是模拟数据做不到的。
（PhysioNet 在本机被限速到约 0.8 KB/s 并频繁断连，EEGMMIDB 脚本保留但不可用。）

预处理版已经做过 128 Hz 降采样、EOG 去除、4–45 Hz 带通，所以这里不再做滤波。

特征（14 导，2 s 窗，0.1 s 步长，Welch）：

| 六参数 | 由什么算来 | 依据 |
|---|---|---|
| `activation` | 相对 β 功率 + 0.5 × 额区 α 不对称（ln αF4 − ln αF3） | β 升高对应唤起；左额相对活跃对应趋近动机 |
| `stability` | α 相对功率在近 8 帧内波动的反向 | α 越平稳越接近闭眼放松态 |
| `complexity` | 4–45 Hz 谱熵（归一化） | 谱越平坦，视觉信息量越大 |
| `change` | 唤醒度的短时变化速度 | 状态转换而非状态水平 |
| `focus` | Pope 参与度 β/(α+θ)，取 FC5 / FC6 / F3 / F4 | 经典注意参与度指数 |
| `quality` | 1 − 4 × 伪迹样本比例（超 4 MAD） | DEAP 无阻抗记录，只能用伪迹代理 |

归一化：同一 trial 内做 5–95 百分位映射到 0–1，再做一阶指数平滑（α = 0.3，`change` 取 0.5）。
百分位归一保证同一被试内部差异可见；**跨被试不可直接比较**，正式实验需改为固定基线
（静息 60 s 或眼闭基线）后再映射。

限制（写论文时必须写清）：这是离线回放，不是在线闭环；DEAP 的情绪标签是看完 MV 后的
自评，与实时视觉反馈的因果链不同；`quality` 不是真阻抗。

## 验收

功能：浏览器可启动；三版可切换；四预设可切换；可暂停/继续；可导出 PNG / JSON；模拟连续变化；断流不崩溃。

视觉：三版一眼可分但同一图案；环带连贯无空隙；叠影版错位处出现更深几何区；折光版有暗部与亮边反差且中心不失焦；动态不闪烁跳变；状态变化可被感知。

研究：每帧状态可记录；映射参数独立；视觉代码不依赖设备；模拟可替换为 PM/EEG；同一输入可回放；三版可比较。
